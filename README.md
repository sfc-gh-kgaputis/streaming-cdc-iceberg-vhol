# Build Real-Time Pipelines on Iceberg with AI Agents

Virtual Hands-On Lab. You build a real-time pipeline for a fictional manufacturer: change data
capture from an operational database lands in **Apache Iceberg** tables, **Dynamic Tables** refine it
continuously, and an **AI agent** answers questions about what is happening on the plant floor. You
build it by prompting CoCo (Cortex Code), not by pasting SQL.
